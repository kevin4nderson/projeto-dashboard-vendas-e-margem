# 📊 Dashboard de Vendas e Margem

![Dashboard](dashboard.png)

## 📌 Sobre o projeto
Desenvolvimento de um dashboard no Power BI para análise de faturamento, margem de lucro e custos logísticos, com foco em geração de insights estratégicos.

## 🛠️ Tecnologias utilizadas
- Power BI
- Power Query (ETL)
- DAX
- Excel

## 📈 Análises realizadas
- KPI de média de valor de venda
- Análise de faturamento por modo de envio (~12,6 Mi)
- Margem de lucro ao longo do tempo
- Lucro por categoria de produto
- Comparação de custo de envio por mercado

## 💡 Principais insights
- Identificação de impacto logístico no faturamento
- Diferença de custo entre mercados globais
- Variação da margem ao longo dos anos

## 📁 Arquivos
- `dashboard.pbix`: arquivo principal do projeto
- `dados.xlsx`: base de dados utilizada
